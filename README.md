# Claude Code Capstone — Agentic SDLC Demo

This project demonstrates a full **Agentic SDLC Pipeline** built with **Claude Code**, mirroring the GitHub Copilot capstone but driven entirely through Claude Code agents, prompts, and hooks.

## Use Case: Automated Documentation Sync

A Python pipeline that detects source code changes and automatically synchronises the affected Markdown documentation — built step-by-step through eight SDLC stages, each guided by a dedicated Claude agent.

## How to Run the Pipeline

Each SDLC stage has a dedicated Claude agent in `.claude/agents/`. Invoke them in order:

```
Stage 1  →  @requirement-agent
Stage 2  →  @architecture-agent
Stage 3  →  @design-review-agent
Stage 4  →  @implementation-planning-agent
Stage 5  →  @implementation-agent
Stage 6  →  @code-review-agent
Stage 7  →  @verify-agent
Stage 8  →  @create-pr-agent
```

### Starting Point

The user story is already seeded in `artifacts/user_story.md`.
Run `@requirement-agent` to begin Stage 1.

## Comparison with GitHub Copilot Capstone

| GitHub Copilot | Claude Code |
|---|---|
| `.github/copilot-instructions.md` | `CLAUDE.md` |
| `.github/agents/*.agent.md` | `.claude/agents/*.md` |
| `.github/skills/` | Claude skills / slash commands |
| `.vscode/mcp.json` MCP config | Claude Code MCP settings |
| Confluence MCP server | `../mcp_servers/confluence-mcp-server/` |

## Running Tests (after Stage 5 + 7)

```bash
pip install -r requirements-dev.txt
pytest tests/ -v --cov=src
```

## Running the Sync Engine (after Stage 5)

```bash
# Manual mode
python scripts/run_sync.py --mode manual

# PR mode
python scripts/run_sync.py --mode pr --base-ref HEAD~1 --head-ref HEAD
```
